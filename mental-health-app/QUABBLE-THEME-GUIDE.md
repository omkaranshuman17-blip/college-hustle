# Quabble-Inspired Theme Guide

Your mental health app has been transformed with a warm, mind-easing yellowish-brown theme inspired by Quabble.app!

## 🎨 Theme Overview

**Primary Colors:**
- **Quabble Brown**: #b08554 (mind-easing, warm brown)
- **Quabble Cream**: #fefdfb (soft, calming cream)
- **Quabble Sage**: #94a088 (peaceful green-gray)
- **Quabble Yellow**: #f9d23f (cheerful, uplifting)

**Typography:**
- **Primary Font**: Nunito (rounded, friendly)
- **Display Font**: Poppins (welcoming headings)
- Both fonts create the soft, approachable feel of Quabble

## 🌟 Key Features

### 1. **Warm Color Palette**
- Light mode: Cream backgrounds with brown text
- Dark mode: Rich brown backgrounds with cream text
- Gentle gradients throughout for a soothing experience

### 2. **Rounded, Friendly Design**
- Extra rounded corners on cards and buttons
- Soft shadows and gentle animations
- Quabble-style hover effects with subtle lifts

## 🎨 Color Classes

### Background Colors
- `quabble-bg-warm` - Light, warm gradient
- `quabble-bg-cozy` - Dark, cozy gradient

### Text Colors
- `quabble-text-primary` - Main text color (adaptive)
- `quabble-text-accent` - Accent text (yellow)

### Utility Classes
- `quabble-rounded` - 1.5rem border radius
- `quabble-rounded-lg` - 2rem border radius
- `quabble-rounded-xl` - 2.5rem border radius
- `quabble-shadow` - Warm, soft shadows
- `quabble-hover` - Gentle hover animations
- `quabble-border` - Theme-appropriate borders

## 🌙 Theme Toggle

The app automatically switches between:
- **Light Mode**: Bright, cheerful cream backgrounds
- **Dark Mode**: Cozy, warm brown backgrounds

Both modes maintain the same welcoming, mind-easing aesthetic that Quabble is known for.

## 🚀 Getting Started

1. The theme is automatically applied to your app
2. Use the pre-built component classes for instant Quabble-style elements
3. Combine utility classes for custom styling
4. The theme responds to your existing dark/light mode toggle

## ✨ Design Philosophy

This theme embodies Quabble's core values:
- **Calm**: Warm, soothing colors that ease the mind
- **Safe**: Gentle, non-threatening visual design
- **Healthy**: Colors and shapes that promote wellbeing
- **Cute**: Playful, rounded elements that bring joy
- **Joyful**: Cheerful accents that make mental health practices engaging

Your app now has the same "calm, safe, healthy, cute" feeling that users love about Quabble!
